# Spirit set (Paper plugin)
Build: `gradle build` -> build/libs/SpiritSakura-1.0.0.jar
Themes: crimson, ember, emerald, abyss, royal, frost, obsidian, ivory  (config `pack.theme` or `/sakura theme <name>`)
Commands (perm spiritsakura.admin): /sakura list | themes | theme <name> | give <item|all> [player] | pack [player] | reload
